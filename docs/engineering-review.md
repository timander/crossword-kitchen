# Engineering review

This review covers code quality, security (mapped to the OWASP Top 10), code smells, and testing. It explains what was found and what was changed. The app is a static, client-only page with no server, no accounts, and no network calls, so most risks are about the browser (DOM XSS, untrusted saved data) and the supply chain (dependencies, CI).

## Security

| Area (OWASP 2021)                            | Finding                                                                                                                              | What we did                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A03 Injection: DOM XSS**                   | The notice banner built HTML strings with `innerHTML` and a hand-written escaper. It was safe at the time, but fragile.              | Every DOM write now uses `textContent`/`append` through a small `el()` helper. ESLint's `no-unsanitized` rule blocks `innerHTML`, `insertAdjacentHTML`, and `document.write`. **Trusted Types** are enforced by CSP, so the browser itself refuses HTML-string sinks.                                                                                                                                                                                                                    |
| **A05 Security misconfiguration**            | No Content-Security-Policy.                                                                                                          | The build adds a strict CSP `<meta>`: `default-src 'none'`. Scripts and styles are allowed only by **SHA-256 hash** of the exact inline code. It also sets `img-src data:`, `base-uri 'none'`, `form-action 'none'`, `object-src 'none'`, and `require-trusted-types-for 'script'`. Changing the `@page` size now goes through the CSSOM, because that stays allowed under the CSP. `<meta name="referrer" content="no-referrer">`.                                                      |
| **A04 Insecure design / A08 Data integrity** | Saved state from `localStorage` was trusted as-is after `JSON.parse`. Bad or tampered data could crash the app or inject odd values. | `parseState()` rebuilds state field by field. It checks types, enums, string and list lengths, grid bounds, and answer letters, and drops anything malformed. It is covered by tests with hostile input.                                                                                                                                                                                                                                                                                 |
| **A04 Insecure design: resource limits**     | There was no limit on word count or length. A huge pasted list could make generation slow and the page unprintable.                  | `LIMITS` sets 60 words, 30 characters per word, 24 answer letters, and 200 characters per clue. Inputs use `maxLength`, and bulk import is clamped.                                                                                                                                                                                                                                                                                                                                      |
| **A06 Vulnerable components**                |                                                                                                                                      | **No runtime dependencies**: the shipped file is only our code. `pnpm audit` runs in CI and fails on high-severity findings. There were 5 _moderate_ advisories in development-only transitive packages (`qs` via Stryker, `minimatch` via an ESLint plugin), fixed with `pnpm` overrides. Dependabot opens weekly grouped updates with a cooldown. `minimumReleaseAge: 1440` refuses package versions less than a day old, which protects against freshly published malicious releases. |
| **A08 CI/CD integrity**                      | Actions were referenced by moving tags (`@v4`). The workflow had pages/id-token write permissions on every job.                      | Every action is **pinned to a commit SHA**, with the version noted in a comment. Workflow permissions default to `contents: read`, and only the deploy job gets `pages`/`id-token` write. `persist-credentials: false` on checkout. `--frozen-lockfile` installs.                                                                                                                                                                                                                        |
| Clickjacking / headers                       | GitHub Pages can't set response headers, so `frame-ancestors` and `X-Frame-Options` aren't possible.                                 | Accepted risk: the page has no sensitive actions or data to hijack. If it's ever moved to a host with header control, add `frame-ancestors 'none'` and the CSP as headers.                                                                                                                                                                                                                                                                                                               |
| Privacy                                      |                                                                                                                                      | Everything stays in the user's browser. There are no analytics, cookies, or network requests, and `connect-src` is blocked by `default-src 'none'`.                                                                                                                                                                                                                                                                                                                                      |

## Code quality and code smells

| Smell                            | Before                                                                                                               | After                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **God module**                   | `main.ts` (~700 lines) held state, persistence, the editor, rendering, keyboard play, fitting, printing, and themes. | Split by responsibility. `src/core/` is pure logic with no DOM: generator, puzzle model and navigation, words, state validation, page fitting, themes. `src/ui/` has one module per concern: `sheet` (rendering only), `player` (interaction), `editor`, `layout` (sizing), `app` (wiring), `store`, `storage`, `dom`, `fx`. `main.ts` is a 30-line composition root. |
| Global mutable state             | Module-level `let state` was mutated from everywhere.                                                                | One observable `Store` with immutable updates. Modules subscribe to the fields they care about (`changed(...)`).                                                                                                                                                                                                                                                      |
| Listener churn                   | Every render re-attached about 5 listeners to each of 150+ cells.                                                    | **Event delegation**: one set of listeners on the sheet and on the word list, attached once.                                                                                                                                                                                                                                                                          |
| Logic tangled with DOM           | Navigation rules (next cell, next word, check, solved) lived inside DOM handlers.                                    | They are now pure functions in `core/puzzle.ts`, unit-tested and mutation-tested.                                                                                                                                                                                                                                                                                     |
| Non-null assertions and casts    | `null!`, `!`, and `as HTMLInputElement` were used throughout.                                                        | `noUncheckedIndexedAccess` is on. A typed `byId(id, HTMLInputElement)` checks element types at runtime. Lint forbids `!` in source.                                                                                                                                                                                                                                   |
| Magic numbers                    | DPI `96`, page sizes, and fit constants were scattered around.                                                       | `PAGE_SIZES`, `CSS_DPI`, `FIT`, `LIMITS`, and the generator constants are named and kept in one place.                                                                                                                                                                                                                                                                |
| Duplicated helpers               | `cellKey`, direction steps, and normalizing were repeated across files.                                              | Shared in `core/grid.ts` and `core/words.ts`.                                                                                                                                                                                                                                                                                                                         |
| Hidden side effects in rendering | `renderSheet` also fitted the page, highlighted, and updated progress.                                               | `renderSheet` only builds DOM and returns references. `layout.apply` and `player.refresh` do the rest.                                                                                                                                                                                                                                                                |
| `<form method="dialog">`         | Implicit dialog submission.                                                                                          | Explicit buttons. This also keeps `form-action 'none'` in the CSP accurate.                                                                                                                                                                                                                                                                                           |

**Patterns used (SOLID, kept simple):**

- **Single responsibility:** each module has one job.
- **Open/closed:** themes are CSS token blocks plus a single list entry. Word banks are data files plus one registry line.
- **Dependency inversion:** `persist()`, `loadState()`, `mountEditor({ confirm })`, and `generate({ random, now })` take their dependencies as parameters, so tests can pass in fakes.

## Bugs found by the new tests and tools

- **Lost edits on close:** saves waited 250 ms after the last change, so closing or reloading the tab right after a change lost it. Saves now run immediately on `pagehide`. The Playwright reload test caught this.
- **Shift+Tab from no word** went to the second-to-last word instead of the last. A mutation-testing follow-up test caught this.
- **Give-away clue:** "Temper" had a clue containing "temperature". The word-bank test now checks every bank for this.
- **Hard-coded `96`** in the sheet zoom instead of the shared DPI constant, flagged by knip as an unused export.

## UI and accessibility

- Minimal Ink is the default theme. Saved theme choices are kept.
- **Phones:** below 760 px the sheet becomes a scrolling layout instead of a shrunken page. Squares are sized to the screen (at least 14 px, usually 25–40 px). Clues sit in one column. Inputs are at least 16 px so iOS doesn't zoom in on focus. Word rows stack. Printing from a phone still produces the full one-page layout.
- **Show/hide the words panel** with a toolbar button (`aria-expanded` and `aria-controls`). The choice is remembered.
- Grid squares have spoken labels such as "3 across, letter 2 of 7". The toolbar has `role="toolbar"`. Notices and warnings are live regions. Buttons have visible focus rings. `prefers-reduced-motion` turns off animation and confetti.

## Testing

| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unit            | Vitest                                                                                                                                                                 | `src/core` at about 99%: generator validity for all banks (seeded), parsing, validation, navigation, fitting, state parsing with hostile input                                                                                                           |
| DOM integration | Vitest + happy-dom                                                                                                                                                     | Mounts the real `index.html`: typing, arrows, Tab, Backspace, mobile input, check, reveal, solve, editor, bulk edit, bank load, themes, panel toggle, paper size, print                                                                                  |
| Coverage        | `@vitest/coverage-v8`                                                                                                                                                  | Thresholds: 85% lines/functions/statements, 80% branches. Currently about 94% lines and 86% branches. Summary is posted to the CI job page.                                                                                                              |
| Mutation        | Stryker                                                                                                                                                                | `src/core`. The run fails below 60%. See `reports/mutation/index.html`. Most survivors are scoring weights in the generator, where many values produce equally valid puzzles.                                                                            |
| End-to-end      | Playwright                                                                                                                                                             | The production build on desktop Chrome and a Pixel 7 profile: no console or CSP errors, playing, saving across reloads, **exactly one PDF page** for both the puzzle and the key, panel toggle, no horizontal scrolling on the phone, playing by tapping |
| Static analysis | tsc (strict, `noUncheckedIndexedAccess`), typescript-eslint `strictTypeChecked` + `stylisticTypeChecked`, `no-unsanitized`, complexity and size limits, Prettier, knip | Runs in CI on every push and PR                                                                                                                                                                                                                          |
